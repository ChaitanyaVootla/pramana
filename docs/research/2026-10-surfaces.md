# Surfaces: modern reading, canvases and an AI study partner (research, Oct 2026)

A survey for the overhaul round (2026-10-18). It covers (1) learning and reading interfaces that feel current, (2) canvas and board tools for thinking with sources, and (3) how an AI study partner and per-user views should appear without becoming a chatbot. Each part ends with ranked recommendations. Claims cite URLs. **[unverified]** marks claims taken from secondary sources only or not checked.

Screenshots of third-party sites were taken on 2026-10-18 at 1440 px (and 390 px where noted). They are kept **outside the repo**, because they are other people's copyrighted UI: `/private/tmp/claude-501/-Users-chaitanya-dev-social/f07b9826-fd5a-45e7-8bbc-41feddca2296/scratchpad/research-shots/` (`owid-life.png`, `owid-article.png`, `wiki-maurya.png`, `wiki-maurya-390.png`, `linear.png`, `readwise.png`, `brilliant.png`, `met-obj.png`, `rijks-search.png`, `rekhta-ghazal.png`, `ux4g.png`, `mapacademy.png`, `notebooklm.png`, `dia.png`).

**Short version**

- **Reading:** what feels current in 2026 is **provenance as a first-class but quiet layer** (OWID's "Cite this work" and sources with retrieval dates), **a small appearance panel** (Wikipedia's text, width and colour), **rights badges and download on every image** (the Met), **honest empty tiles** (the Rijksmuseum's "not available digitally"), **click-any-word glossaries and script toggles** (Rekhta), and **"X on behalf of Y" activity lines** (Linear).
- **Canvas:** build on **React Flow (xyflow, MIT)** with our own card components, **not tldraw** (its proprietary licence key is incompatible with AGPL self-hosting). Place **references, not copies**. Pin verbatim quotes and flag "updated since you placed this". Link back from every page to the canvases it appears on. On phones, default to a **list view**.
- **AI partner:** **presence driven by real traffic** (Linear's session states), **margin notes anchored to a claim, entity or excerpt**, styled differently from canonical text, **citations checked by the server**, **attempt-first prompts** (the evidence says unguarded AI harms learning), and proposals reviewed like draft PRs.
- **Per-user views** are an **overlay, never a fork**. The canonical claims and evidence always render; "Your view · N changes · Show original".

### What "current" means in 2026 (the common traits)

1. **One strong typographic voice, not decoration.** Brilliant uses a serif display face, Linear uses Inter Display, and OWID uses Playfair-style headings with Lato. Big type, little ornament, generous but not wasteful width.
2. **Colour by system.** Linear's three-variable LCH themes give consistent elevation and an automatic high-contrast mode. Our "colour carries meaning" rule fits; generate the palette in OKLCH.
3. **Dense when wide, calm when narrow.** Wikipedia and Readwise use both side rails at 1440 px and above and collapse them on phones. OWID puts the entity selector beside the chart.
4. **Provenance as a quiet layer you can expand**, not footnote soup: OWID's collapsible "Sources and processing" and the Met's rights badge.
5. **Honest gaps are a design element**: the Rijksmuseum's "not available digitally" tiles.
6. **Agents shown in the activity stream with "on behalf of"** (Linear).
7. **Reader controls are expected**: Wikipedia's Appearance panel, UX4G's A−/A+, Rekhta's script toggle.

**On tldraw and AGPL:** every self-hoster of an AGPL fork would need their own tldraw key. That is an added restriction AGPL forbids unless the copyright holders grant an exception ([GPL FAQ](https://www.gnu.org/licenses/gpl-faq.html#GPLIncompatibleLibs)). Enforcement began with SDK 4.0 (Sept 2025). This is not legal advice, but the risk is plain: avoid it.

**The gap no tool fills:** live tools update silently and snapshot tools go stale silently. None says "**the source changed since you placed this**". Our rule of verbatim quotes against immutable snapshots requires that we do.

| Claude Code "Learning" output style ([docs](https://code.claude.com/docs/en/output-styles))                                                                                                                                                                                   | Claude leaves `TODO(human)` gaps at real decisions, waits, then comments on what the user wrote.                                                                                                                                                                                                                           | An AI that leaves the learner a turn.                                                          |
| ChatGPT study mode ([Axios](https://www.axios.com/2025/07/29/openai-chatgpt-study-mode)) / Claude learning mode ([Anthropic](https://www.anthropic.com/news/introducing-claude-for-education))                                                                                | Socratic questions and hints, but implemented as prompts the user can switch off.                                                                                                                                                                                                                                          | **Guardrails that live only in a prompt are weak**; enforce them in what the server hands out. |

### What the evidence says about AI tutors

| Study                                                                                                                                                                                                            | Result                                                                                                                                                                                                                      | Implication                                                                                        |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Bastani et al., PNAS 2025 ([RePEc](https://ideas.repec.org/a/nas/journl/v122y2025pe2422633122.html), [Wharton](https://knowledge.wharton.upenn.edu/article/without-guardrails-generative-ai-can-harm-education)) | About 1,000 high-school maths students. AI users were overconfident. | Unguarded answers harm learning; hints only remove the harm. Show learners their real performance. |
| Kestin et al., Sci Rep 2025 ([PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC12179260/))                                                                                                                          | An AI tutor beat in-class active learning (0.63 SD), **but** it was given pre-written step-by-step solutions and the platform kept students on each step in order.                                                          | Ground the AI in authored material (for us, the approved excerpts) and structure the steps.        |
| Tutor CoPilot ([arXiv](https://arxiv.org/abs/2410.03017))                                                                                                                                                        | +4 percentage points on mastery (+9 for weaker tutors); more guiding questions, fewer answers given away.                                                                                                                   | Questions before answers.                                                                          |
| Lehmann et al. ### MCP facts that shape the UI (for **connect**)

- **The current spec is 2026-07-28** ([changelog](https://modelcontextprotocol.io/specification/2026-07-28/changelog)):
  - Protocol sessions, `Mcp-Session-Id` and `initialize` are gone; each request carries version, capabilities and `clientInfo` in `_meta`.
  - `subscriptions/listen` replaces the GET stream.
  - `Mcp-Method` and `Mcp-Name` headers are required.
  - Sampling, Roots and Logging are deprecated.
  - **So "connected" must be inferred** from an open listen stream or from the time of the last request. 2025-11-25 clients still use sessions.
- **Security** ([transport spec](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http)): "Servers MUST validate the Origin header… If the Origin header is present and invalid, servers MUST respond with HTTP 403… SHOULD bind only to localhost (127.0.0.1)… SHOULD implement proper authentication."
  - The TS SDK's DNS-rebinding protection is off by default.
  - CVE-2025-66414 affects SDKs before 1.24.0 ([SentinelOne](https://www.sentinelone.com/vulnerability-database/cve-2025-66414/)).
- **Client configs:**
  - Claude Code: `claude mcp add --transport http pramana http://127.0.0.1:3000/mcp --header "Authorization: Bearer …"`. In `.mcp.json` the entry needs `"type": "http"`; an entry with a url but no type is skipped ([docs](https://code.claude.com/docs/en/mcp)).
  - **Claude Desktop custom connectors connect from Anthropic's cloud, so they can't reach localhost** ([support](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)). Use stdio, or `mcp-remote` (third-party).
  - VS Code: `"servers"` with `type: "http"` ([docs](https://code.visualstudio.com/docs/copilot/reference/mcp-configuration)).
- **Claude Code extras:**
  - MCP prompts become `/pramana:<prompt>` slash commands, and resources can be @-mentioned. Use both for "Ask your AI about this".
  - `_meta["anthropic/requiresUserInteraction"]` forces a human prompt on every call to that tool.
  - Server instructions are cut at 4,096 characters.
- **MCP Apps** (`ui://` resources in a sandboxed iframe) is stable and supported by Claude web and Desktop, ChatGPT, VS Code and Cursor, **not Claude Code** ([overview](https://modelcontextprotocol.io/extensions/apps/overview), [matrix](https://modelcontextprotocol.io/extensions/client-matrix)).
- `clientInfo` names the client, not the model. **Label any model name as self-reported.**
